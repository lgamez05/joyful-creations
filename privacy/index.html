Privacy

[PENDIENTE] This page explains the forms in plain language. It is not an approved legal policy.

What the consultation form asks

Full name, email, optional phone, event type, event date, city and state, optional guest count, the pieces you are considering, optional notes, an optional note about how you heard of the studio, and consent to be emailed about the request. It does not ask for a budget, a tax identifier, or a document.

What the stationery form asks

Full name, email, piece type, approximate quantity, the date you need the pieces, an optional finish, optional inspiration images, optional notes, and the same email consent. Images are not uploaded in this review build. A file size limit is not set.

Why those details would be used

They would be used to reply by email about the request. The mailbox named for a future send is info@joyfulcreationsli.com. This review build does not transmit the form, does not store it on a server, and does not share it.

What stays in the browser

A draft may be kept in this browser's session storage so a refresh does not clear the fields. Campaign parameters from the link, if they match the expected pattern, are kept the same way and copied into hidden fields. This site does not set tracking cookies.

What this site does not run

No analytics tool is installed. Advertising pixels are not loaded. The pixel slots in the page head are empty.
